Antes de instalar

Transparência no download

O instalador para Windows ainda não possui certificado de assinatura digital. O Windows pode exibir um alerta SmartScreen. Confira o nome do arquivo e a origem antes de continuar; se não reconhecer a origem, não execute o instalador.

Antes de começar

Preciso criar outra conta no computador?

Não. Use a mesma conta do BrasilCord no navegador ou no aplicativo, desde que esteja conectando ao mesmo serviço.

Existe aplicativo Android ou iOS para baixar?

Não há APK nem aplicativo de loja publicado oficialmente nesta página. Use a versão web ou o atalho na tela inicial.

O aplicativo atualiza automaticamente?

O aplicativo Windows possui sistema de atualização, mas a disponibilidade e o funcionamento dependem da versão instalada. Consulte os lançamentos oficiais para conferir a mais recente.

Como posso entrar durante a manutenção?

Abra a opção Entrar no navegador e utilize a senha de manutenção para liberar a versão normal. O controle por senha no site é apenas uma barreira visual.
